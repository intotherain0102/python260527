HTML5 · CSS3 · JavaScript 공부 페이지

하나의 파일에 HTML, CSS, JavaScript가 함께 들어있는 예제입니다.

HTML5 구조

HTML은 웹 페이지의 뼈대를 정의합니다. 이 예제는 제목, 단락, 버튼, 입력 요소를 포함합니다.

<header> ... </header> <main> <section> ... </section> </main>

CSS3 스타일

CSS는 색상, 배경, 여백, 글꼴을 정의해 페이지를 보기 좋게 만듭니다.

body { background: linear-gradient(...); font-family: Arial, sans-serif; } button:hover { transform: translateY(-2px); }

공부 포인트

  • HTML은 문서 구조(헤더, 섹션, 텍스트, 버튼 등)를 만들어요.
  • CSS는 디자인(색, 크기, 레이아웃, 애니메이션)을 꾸며요.
  • JavaScript는 동작(버튼 클릭, 입력 처리, 화면 변경)을 제어해요.

이 페이지는 하나의 HTML 파일에 HTML5, CSS3, JavaScript를 모두 포함하고 있습니다.
